# Task 1 – Chatbot with Rule-Based Responses

A simple console chatbot made using Python `if/elif` conditions and a few regular-expression checks.

### Features
- Handles greetings
- Gives basic help
- Answers simple questions
- Tells the current date and time
- Ends the conversation with `bye`, `exit`, or `quit`

### Run

```bash
python chatbot.py
```
